# Vestavba dodávky

Společný plán koupě a dostavby obytné dodávky: požadavky, nálezy inzerátů, porovnání koupit vs. postavit, 48V elektro pro práci z auta, půdorys, plán stavby, deník.

Stránka: https://kompicka.github.io/dovca/

Data jsou v `data/db.json`. Změny ve stránce se ukládají jen v prohlížeči; tlačítkem „Zkopírovat změny pro Claude“ je pošlete a zapíšou se do repozitáře. Detaily pro údržbu jsou v `CLAUDE.md`.
